# French voice lines

Save recordings in `public/audio/fr/` using the file name in the table (mp3, m4a, ogg, wav or webm all work, just keep the name before the dot exactly the same). Then run `npm run audio` to tick them off here. Lines without a recording are read by the device's speech voice, so you can record as many or as few as you like.

**Part 1, fixed lines:** 0 of 116 recorded. These never change, so one recording covers every shift. Start here.
**Part 2, lines with dish and drink names:** 0 of 446 recorded. One recording per menu combination. Optional: the device voice reads any you skip.

Speaker notes: "Waiter (Alex)" lines are your replies. Guest lines say which kind of guest is talking, so you can act the mood.
